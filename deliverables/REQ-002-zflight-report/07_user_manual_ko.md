# ZFLIGHT 사용자 매뉴얼

표준 항공 운항 테이블 `SFLIGHT`를 조회하여 결과를 ALV 그리드로 보여주는 리포트 프로그램입니다.

- **프로그램**: `ZFLIGHT` (리포트) · **패키지**: `$TMP` (개발 시스템 로컬 객체)
- **시스템**: NPL, 클라이언트 001 · **조회 대상**: `SFLIGHT`만 읽음 (데이터 변경 없음)
- **요구사항 폴더**: [REQ-002-zflight-report](../index.md) · 기술설계: [02_technical_design.md](02_technical_design.md)
- **영문 버전**: [07_user_manual.md](07_user_manual.md)

## 1. 프로그램 실행

1. 개발 시스템(클라이언트 001)에 로그인합니다.
2. 트랜잭션 `SE38`(ABAP 에디터) 또는 `SA38`(ABAP 리포트 실행)을 실행합니다.
3. 프로그램명 `ZFLIGHT`를 입력하고 **실행**(F8)을 누릅니다.

실행하면 먼저 선택 화면이 나타납니다.

## 2. 선택 화면

| 항목 | 의미 | 기본값 | 예시 |
|---|---|---|---|
| 항공사 (`S_CARR`) | 항공사 코드 범위 | `LH` (포함, 단일값) | `AA` = 아메리칸항공. 범위 편집기(화살표 버튼)로 여러 값 지정 가능 |
| 운항 노선 (`S_CONN`) | 노선(편명) 번호 범위 | 비움 (= 전체) | `0400`~`0402` = 루프트한자 프랑크푸르트–뉴욕 노선 |
| 운항일 (`S_DATE`) | 운항일 범위 | 비움 (= 전체) | `01.01.2017`~`31.12.2019` |
| 최대 건수 (`P_MAX`) | 조회 결과 상한 | 200 | 빠른 확인용으로 줄여서 사용 |

주의 사항:

- 항목을 비우면 해당 조건은 무시됩니다. 전체 항공사를 보려면 기본값 `LH`를 직접 지워야 합니다.
- 데모 데이터의 운항일은 2017~2019년 범위이므로, 그 밖의 기간은 결과가 없습니다.
- 항공사 코드는 대문자입니다 (`lh` 아닌 `LH`).

## 3. 결과 목록 (ALV 그리드)

항공사 + 노선 + 운항일 조합당 한 행이 표시됩니다.

| 컬럼 | 설명 |
|---|---|
| Airline | 항공사 코드 (`LH` = 루프트한자 등) |
| Flight Connection | 노선(편명) 번호 |
| Flight Date | 운항일 |
| Airfare | 항공권 가격 (해당 항공사 통화) |
| Currency | 운임 통화 코드 |
| Plane Type | 기종 (예: `747-400`) |
| Max. Capacity / Occupied | 이코노미 좌석 — 정원 / 사용 |
| Max./Occupied (bus.) | 비즈니스 좌석 — 정원 / 사용 |
| Max./Occupied (1st) | 퍼스트 좌석 — 정원 / 사용 |
| Total | 예약 금액 합계 (`PAYMENTSUM`) |

ALV 툴바에서 정렬, 필터, 레이아웃 변경, 스프레드시트 내보내기 등을 할 수 있습니다. 금액 컬럼은 행별 통화를 따라 표시됩니다.

## 4. 메시지

| 메시지 | 의미 | 조치 |
|---|---|---|
| `No flights found for the given selection.` | 조건에 해당하는 데이터가 없음 | 범위를 넓히거나, 항공사 코드가 대문자인지 확인하거나, 기본값 `LH`를 제거 |

## 5. 기술 사양

- 한 번의 실행에서 최대 `P_MAX`건까지 조회하며, 항공사 → 노선 → 운항일 순으로 정렬됩니다.
- 프로그램은 데이터를 읽기만 하며 생성·변경·삭제를 하지 않습니다.
- `$TMP` 로컬 객체이므로 이 시스템에만 존재하며, 클라이언트 재생성·정리 시 사라질 수 있습니다. 전송이 필요하면 Z* 패키지에 복사본을 만들어야 합니다(SRS 오픈 이슈 참조).
